# capture

Write what this session produced into the vault. Run it when a piece of work is finished, before the context is gone.

## Pull from the conversation

- Decisions reached, each with its reason and the date.
- Facts worth keeping: numbers, names, links, anything that was looked up.
- Open threads: what was left unfinished, and the next action on each.

## Write

- Put each item in the file it belongs in. Match an existing file before making a new one.
- Append under today's date. Do not rewrite what is already there.
- Show the diff before writing. Nothing is saved without a look.

## Leave out

- Anything the file already records.
- Discussion that led nowhere.
- The task restated back. Capture what changed, not what was asked.
